3.1 HTTP

Se trata del llamado y mundialmente conocido Protocolo de Transferencia de Hipertexto, bajo el cual, se rige todo tipo de comunicación dentro de la web. Se rige por 3 conceptos:

  • Cliente-Servidor
  • Protocolo sin Estado
  • Dependencia de TCP/IP

Bajo el uso de 4 métodos:

Estructura de una URL

Una URL, (Uniform Resource Locator) es el elemento necesario por el que todo comienza para que un navegador sepa donde puede acceder a un recurso dentro de la web.

Se conforma por 4 partes: scheme://domain_port/path?query_string#fragment_id

Protocolo Define cómo se realizará la comunicación Dominio y Puerto Define el servidor y, opcionalmente el puerto de conexión Ruta Especifica la ubicación del recurso en el servidor Consulta y Fragmento Añaden parámetros dentro del recurso

Servidores Web

Un servidor web es un sistema que procesa peticiones HTTP/HTTPS y entrega el contenido web solicitado

Arquitectura de una Aplicación Web

  • Todo en un servidor.

    • Servidor web y base de datos en una misma máquina, ideal para desarrollo

  • Separación de componentes.

    • El servidor web y la base de datos se encuentran en máquinas distintas para un mejor rendimiento

  • Cloud Computing.

    • Se tienen múltiples servidores web gestionados por un balanceador de estados

  • Granjas de Servidores.

    • Se incluyen plataforma con infraestructuras complejas de servicios escalables, como AWS

Socket

Un Socket se define como la combinación de una dirección IP y un puerto para la comunicación entre un cliente y un servidor

Ya que precisamente, para que se dé una comunicación, incluso mediante HTTP, se debe de establecer una conexión TCP/IP, que viene necesitando dichos datos por parte del servidor

3.3 CSS

Veíamos antes en HTML, que este era exclusivamente para la definición de la estructura y contenidos de una página web.

Ahora, para lograr darle más detalles a la aplicación web, se usa CSS. Un lenguaje de definición de presentación de los contenidos de una página web.

Cascading Style Sheets

Existen varios niveles de CSS, 1, 2, etc. El más aceptados por loss navegadores, es el nivel 2.1 que actualmente cuenta con alrededor de 200 declaraciones diferentes.
