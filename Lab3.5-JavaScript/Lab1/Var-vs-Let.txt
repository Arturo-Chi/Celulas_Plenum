VARIABLES
    Diferencia entre VAR y LET

    - Si declaramos una variable con la palabra var
        Esa variable va a ser de scope global.

    - Si declaramos una variable con la variable LET
        Esa variable va a tener un scope de bloque.

    Resulta incluso una mala práctica usar VAR, lo mejor para evitar problemas de reasignación de valores es usar LET

    Las var se guardan dentro del objeto WINDOW
