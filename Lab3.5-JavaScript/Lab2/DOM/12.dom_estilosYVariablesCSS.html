Atributos y Data atributes

El estandar de html no permite crear nuestros propios atributos (Estos son los data atributes) ¿Como se escriben? En la etique html que queramos podemos agregar: data-[name] = "" Para crearlos debemos empezar a escribirlo con "data-" lo siguiente es a nuestro gusto data-description ="Document Object Model"
