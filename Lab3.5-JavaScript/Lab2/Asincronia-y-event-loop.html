Asincronia y event loop

JavaScript es un lenguaje de un solo hilo (Single Thread) Esa principal ventaja hace que nosotros no tengamos porque preocuparnos por temas como la concurrencia, ya que se trabaja solo una tarea a la vez. JavaScripr es single thread, (sus hermanos simplifican código) por lo tanto no se pueden realizar operaciones largas como el acceso a la red sin que se bloquee el hilo principal. Imaginemos que solictamos datos a una API, puede tardar o no en procesar la solicitud, por lo tanto el resto del código se bloquearía hasta tener un response. Para eso es la asincronía, poder realizar operaciones largas sin hacer bloqueos en el resto del código. conceptos básicos: -- EVENT LOOP EN JavaScript AL ser JS un lenguaje de un solo hilo, el procesamiento se da en los threads, unidades básicas de cada proceso que realiza nuestra máquina.
